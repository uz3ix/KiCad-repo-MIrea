## Что прикрепить

`main.c`, `app_logic.h` и этот файл. Код предназначен для существующей схемы `Demidov_P1.kicad_sch` на STM32F103C8Tx.

## Подключения

| Вывод | Подключение | Настройка программы |
|---|---|---|
| PA0 | R1 220 Ом и светодиод D1 | TIM2_CH1, ШИМ 1 кГц, активный высокий уровень |
| PA1 | Кнопка SW1 на землю, R2 10 кОм к +3,3 В | Цифровой вход; 0 означает нажатие |
| PA2 | Движок потенциометра RV1 10 кОм | ADC1, канал 2, диапазон 0–4095 |

## Алгоритм

1. Выбирается внутренний генератор HSI 8 МГц. Внешний кварц для этой схемы не нужен.
2. PA0 переводится в режим выхода таймера. TIM2 формирует ШИМ: 8 МГц / (7 + 1) / (999 + 1) = 1 кГц.
3. PA1 настраивается как вход без внутренней подтяжки: внешний R2 уже имеется на схеме.
4. PA2 переводится в аналоговый режим. АЦП включается и калибруется.
5. Примерно раз в миллисекунду считываются кнопка и АЦП. Состояние кнопки принимается после 20 последовательных одинаковых отсчётов, чтобы уменьшить влияние дребезга.
6. При нажатой кнопке `CCR1 = ADC × 1000 / 4095`. При отпущенной кнопке CCR1 равен нулю.

При минимальном положении RV1 светодиод выключен даже при нажатии. При максимальном — включён на полную яркость, пока кнопка удерживается. Нажатие не переключает режим с фиксацией; это именно удержание. Положение ручки между крайними точками плавно меняет коэффициент заполнения ШИМ.

В отладчике можно наблюдать `adc_value`, `button_pressed` и `pwm_value`.

## Сборка

Это исходники приложения, не готовый HEX и не программа для запуска внутри KiCad.

Нужен проект для **STM32F103C8Tx / Cortex-M3** с CMSIS Core и CMSIS Device STM32F1, например в STM32CubeIDE:

- определение препроцессора `STM32F103xB`;
- заголовки `stm32f1xx.h`, `stm32f103xb.h`, CMSIS Core;
- стандартные `system_stm32f1xx.c`, startup и linker script для STM32F103C8;
- Flash: 64 Кбайт с адреса 0x08000000; RAM: 20 Кбайт с адреса 0x20000000;
- заменить исходный `main.c` этим файлом и положить рядом `app_logic.h`;
- библиотека HAL не используется; `USE_HAL_DRIVER` для этих исходников не требуется.

Системный startup вызывает SystemInit, затем main. Программа самостоятельно переключает тактирование на HSI 8 МГц. Не добавляйте второй main или дополнительную перенастройку частоты.

## Проверка и ограничения

Сверены PA0, PA1 и PA2 по списку соединений текущей схемы. На компьютере скомпилированы и выполнены тесты функций из `app_logic.h`: все 4096 значений АЦП, границы и монотонность ШИМ, отпускание/нажатие и дребезг кнопки. Полная прошивка под ARM не собиралась; доступного целевого компилятора в среде нет. Прошивка платы и аппаратная проверка не выполнялись. Ожидания готовности тактирования и АЦП блокирующие, без диагностики аппаратного отказа.

## Краткое описание для отчёта

Разработана программа управления светодиодом на STM32F103C8Tx. Кнопка SW1 на PA1 разрешает включение светодиода, а потенциометр RV1 на PA2 задаёт его яркость. Аналоговый сигнал преобразуется 12-разрядным АЦП; результат определяет коэффициент заполнения ШИМ таймера TIM2 на PA0. Для кнопки предусмотрено программное подавление дребезга. Аппаратная проверка программы не проводилась.
